<summary><b>🤟 PSL Sign Language Recognition App</b> | <i>Final Year Project</i></summary>

**The Mission:** Teaching machines to understand Pakistan Sign Language—because everyone deserves to be heard.

**Key Achievements:**
- Trained **ST-GCN neural network** on 15,000+ real sign language videos
- Extracted **75-point skeleton graphs** using MediaPipe Holistic
- Automated **55% ROI preprocessing pipeline** with batch processing
- Built interactive **PSL Quiz** module in React Native + Expo
- **Upgraded:** LSTM → ST-GCN = Major accuracy improvement 📈

**Stack:** Flutter | Python | Firebase | ST-GCN | MediaPipe | React Native
