## 📂 Flagship Projects

### 🤟 **PSL Sign Language Recognition App** *(Final Year Project)*
**Tech Stack:** Flutter | Python | Firebase | ST-GCN | MediaPipe | React Native

> *Teaching machines to understand sign language. Because inclusion matters.* 🌍

- 🎥 Trained **ST-GCN model** on 15,000+ real-world sign language videos for skeletal gesture recognition
- 🔬 Engineered **3D skeleton graphs with 75 keypoints** using MediaPipe Holistic with nose-based normalization
- ⚡ Automated preprocessing pipeline with **55% ROI cropping** and recursive batch processing
- 📱 Built interactive **PSL Quiz module** in React Native for in-app learning evaluation
- 🔄 Model upgrade: LSTM → ST-GCN = **Major accuracy boost** 📈
